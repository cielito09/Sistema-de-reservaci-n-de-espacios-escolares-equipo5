# 🏫 Sistema de Reservación de Espacios Escolares — Equipo 5

Aplicación web diseñada para administrar, consultar disponibilidad y gestionar la reservación de aulas, laboratorios y espacios comunes dentro de una institución educativa.

## 📋 Características principales
- Visualización de espacios escolares disponibles.
- Registro y control de reservaciones por fecha y horario.
- Gestión de usuarios y administración de espacios.

## 🛠️ Tecnologías utilizadas
- **Backend:** PHP
- **Frontend:** HTML5, CSS3, JavaScript
- **Base de datos:** MySQL / MariaDB *(ajusta si usas otra)*

## 📁 Estructura del proyecto
```text
├── js/                 # Scripts y validaciones del lado del cliente
├── php/                # Lógica del servidor y vistas principales
│   └── index.php       # Punto de entrada de la aplicación
└── README.md           # Documentación del proyecto
```

## 🚀 Instalación y ejecución local
1. Clona el repositorio dentro de la carpeta pública de tu servidor web (por ejemplo, `/var/www/html/`):
   ```bash
   git clone <URL-DEL-REPOSITORIO>
   ```
2. Inicia los servicios de **Apache** y **MySQL** en tu equipo.
3. Importa la base de datos *(si aplica)* y ajusta las credenciales de conexión dentro de `php/`.
4. Abre tu navegador y entra a:
   ```text
   http://localhost/Sistema-de-reservaci-n-de-espacios-escolares-equipo5/php/index.php
   ```
